Style With Charm is a minimalist, elegant, Pinterest-inspired home decor and interior design WordPress theme.

== Description ==
Style With Charm is built for home decor publications, interior designers, and lifestyle creators. Features include:
* Pinterest-inspired Masonry Feed: Dynamically loads new WordPress blog posts.
* Dynamic Category Cards: Automatically displays WordPress categories with image covers.
* Editor's Picks Magazine Section: Promotes sticky or featured articles.
* AJAX Progressive Loading: Seamless "Load More" without page refreshes.
* Editorial Typography: Cormorant Garamond serif headings with clean Jost sans-serif body.
* Social Sharing: Direct Pinterest Pin, Facebook, and email buttons.
* WordPress Customizer Support: Customize hero banner, text, colors, and social links in real time.

== Installation ==
1. In your WordPress admin, go to Appearance > Themes.
2. Click "Add New" and then "Upload Theme".
3. Choose the style-with-charm-theme.zip file and click "Install Now".
4. Click "Activate".
5. Go to Appearance > Customize to configure your hero banner, logo, and social links.
